Introduction

API REST para gerenciamento de clientes, contratos e cobranças.

Base URL: http://localhost:8080

Esta documentação descreve a API do sistema Amar Assist Billing, desenvolvido como desafio técnico.

A aplicação permite gerenciar clientes e contratos, gerar e consultar cobranças, aplicar automaticamente multa diária de 1% após o vencimento e registrar pagamentos.

A API utiliza Laravel Sanctum para autenticação da SPA através de sessão e cookies seguros.

Principais recursos

  • Gerenciamento e pesquisa de clientes;
  • Contratos PF e PJ;
  • Ciclo de cobrança com ajuste automático ao número de dias do mês;
  • Cobranças via PIX, boleto e cartão;
  • Cálculo automático de multa por atraso;
  • Controle de cobranças abertas e pagas;
  • Processamento assíncrono com Redis e Laravel Horizon;
  • Atualizações em tempo real com Laravel Echo e WebSockets.

Ambiente local

http://localhost:8080

http://localhost:8080/app

Autenticação

A aplicação utiliza Laravel Sanctum no modo SPA com autenticação baseada em sessão.

O fluxo de autenticação é:

  1. Solicitar o cookie CSRF através de GET /sanctum/csrf-cookie;
  2. Realizar o login através de POST /login;
  3. Utilizar a sessão autenticada para acessar os endpoints protegidos;
  4. Encerrar a sessão através de POST /logout.

Os endpoints de clientes, contratos e cobranças exigem autenticação.

Request      

POST api/contracts/{contract_id}/charges

Headers

Content-Type        

Example: application/json

Accept        

Example: application/json

URL Parameters

contract_id   integer     

The ID of the contract. Example: 2

Body Parameters

base_amount   string     

Must match the regex /^\d+(.\d{1,2})?$/. Example: 2.77

payment_method   string     

Example: CARD

Must be one of:
  • BOLETO
  • CARD
  • PIX
reference_date   string  optional    

Must be a valid date in the format Y-m-d. Example: 2026-08-24

barcode   string  optional    

This field is required when payment_method is BOLETO. Must not be greater than 100 characters. Example: tdsufvyvddqamniihfqco

pix_key   string  optional    

This field is required when payment_method is PIX. Must not be greater than 255 characters. Example: ynlazghdtqtqxbajwbpil

card_token   string  optional    

This field is required when payment_method is CARD. Must not be greater than 255 characters. Example: pmufinllwloauydlsmsju

card_brand   string  optional    

This field is required when payment_method is CARD. Must not be greater than 30 characters. Example: ryvojcybzvrbyickznkyg

card_last_four   string  optional    

This field is required when payment_method is CARD. Must be 4 digits. Example: 8107

card_exp_month   integer  optional    

This field is required when payment_method is CARD. Must be between 1 and 12. Example: 1

card_exp_year   integer  optional    

This field is required when payment_method is CARD. Must be at least 2026. Example: 1295
